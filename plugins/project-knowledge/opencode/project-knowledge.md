# Project Knowledge

For non-trivial work in a Git repository, load the `project-knowledge` Skill and resolve the current repository before relying on prior project decisions or implementation history. Treat knowledge search/get/history results as read-only, retrieve full entries only after focused search, and verify older knowledge against the current code. Automatic OpenCode capture is the primary conversation truth. Call `project_knowledge_record_requirement` only for an explicitly requested supplement or when automatic capture is known to be unavailable; it appends one user Prompt to the same ConversationStore and never starts analysis.
