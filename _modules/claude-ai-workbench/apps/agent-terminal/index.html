设置

模型供应商

一家供应商配置一次，Claude Code、Codex 与 OpenCode 共用。填写两种 API 端点及对应模型名，API Key 单独加密存储。

自定义供应商
选择或添加一个供应商。

Agent 发现

自动扫描本机可用的 Agent 程序;不可用或未接入的会如实标注。

会话捕获

默认关闭:终端是内部 AI 运行时,你在这里与 AI 的对话不会进入开发对话记录(知识库的会话浏览)。开启后,此后新建的终端对话会像 CLI 工具对话一样被留档;已存在的会话不受影响。

关于

本页面由 Agent Terminal 服务直接托管,与 API 同版本发布;宿主可通过 iframe 嵌入本页(UI 与服务同版本,天然消灭版本漂移)。

添加项目

手动添加项目:填写本地文件夹的绝对路径作为工作区根目录(点「添加项目」通常直接弹出系统文件夹选择器,无需手填)。
